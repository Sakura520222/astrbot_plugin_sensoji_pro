# 项目概述：浅草寺抽签插件-PRO

## 1. 项目简介
这是一个基于 AstrBot 框架的模拟日本浅草寺抽签功能的聊天机器人插件，用户可通过命令随机抽取签文、查看运势，并借助大语言模型获得签文解读。

## 2. 技术栈
- **框架**：AstrBot（插件化机器人框架）
- **语言**：Python
- **依赖库**：未在 README 中明确列出，但从代码结构推断可能包含异步处理、定时任务、字体渲染等相关库
- **LLM 集成**：支持调用大型语言模型进行智能解签
- **数据存储**：本地数据文件（sensoji_data.py）管理签文内容

## 3. 项目结构
- **main.py**：插件主逻辑，包含命令注册、抽签算法、转运功能实现及 LLM 解签调用入口。
- **sensoji_data.py**：签文数据集，存储吉凶结果（大吉、吉、凶等）及对应的运势描述文本。
- **_conf_schema.json**：插件配置 schema，定义用户可配置的参数（如大模型接口、清理周期等）。
- **metadata.yaml**：插件的元信息文件，供 AstrBot 识别插件名称、版本、作者等。
- **fonts/**：存放多款中/日文字体文件（如 BGTXT.ttf、FZSTK.ttf 等），用于生成带排版的美观签文图片。
- **CHANGELOG.md**：版本更新记录。
- **LICENSE**：开源许可证。
- **.gitignore**：Git 忽略规则。

## 4. 开发约定
- **命令前缀**：插件使用 `/抽签`、`/抽签帮助`、`转运`、`解签` 等简短指令，同时支持自然语言触发如“解一下签”。
- **异步清理机制**：采用定时任务自动清理生成的临时签文文件，避免资源堆积（见 v1.2.0 更新内容）。
- **模块分工**：数据层（sensoji_data.py）与逻辑层（main.py）分离；字体资源独立存放于 fonts/ 目录。
- **配置规范**：使用 JSON Schema 定义配置项，确保插件可被 AstrBot 配置系统正确识别。
- **兼容性提示**：LLM 解签功能注明在特定大模型下可能无法使用，体现功能可选且依赖外部服务。
